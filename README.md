# ODIN-PROJECT: RESTAURANT

## Description:
This project is to practice DOM manipulation and using modules when creating website projects. Its theme is to create a website for some restaurant. I decided to create it for a hypothetical tea shop The Jasmine Dragon if ever it were a real place from the show The Avatar The Last Airbender.

## Skills used:
The skills used in making this project possible are:
- Basic HTML and CSS manipulation
- Basic JavaScript DOM Manipulation
- Basic Webpack knowledge in stitching different modules together
- Basic knowledge in deploying a website
